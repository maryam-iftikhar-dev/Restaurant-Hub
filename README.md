# Restaurant HUB

## Description
Restaurant HUB is a comprehensive restaurant management system designed to connect **customers, employees, delivery personnel, and administrators** on a single platform.

The system enables customers to browse restaurant menus, place orders, manage reviews, and explore promotions. Employees can manage restaurant operations, process orders, and monitor customer feedback. Delivery personnel handle order deliveries and update delivery statuses, while administrators manage menus, promotions, and overall system operations.

The system is preloaded with restaurants, menus, employees, delivery staff, customers, promotions, reviews, and order data from multiple restaurants and locations in Islamabad to provide a complete simulation of a food delivery ecosystem.

## Features

### Main Menu
- Customer Login and Sign Up
- Admin Panel Access

- Delivery Person Access

---

## Customer Functionalities
Customers can:

- Login and Sign Up
- Reset account credentials
- View all restaurants and menus
- View menu of a specific restaurant
- View available promotions
- Add reviews
- Delete reviews
- View top 5 positive and negative reviews
- Place orders
- View order details
- Confirm orders

---

## Admin Functionalities
Admin can:

- Login
- Reset account credentials
- View all restaurants and menus
- View menu of a specific restaurant
- View promotions
- View top 5 positive and negative reviews
- Add dishes to restaurant menus
- Edit dishes
- Delete dishes
- View all customer orders
- View processed orders
- Add promotions
- Delete promotions

**Note:** Restaurant add/edit/delete functionality exists in the backend but is not exposed to users for simplicity.

---

## Employee Functionalities
Employees can:

- Login
- Reset account credentials
- View assigned restaurant details
- View restaurant menu
- View promotions
- View customer reviews
- View all restaurant orders
- View processed orders
- View current order and status

---

## Delivery Person Functionalities
Delivery personnel can:

- Login

- View restaurant details and menus
- View promotions

- View processed delivery orders
- View order delivery paths
